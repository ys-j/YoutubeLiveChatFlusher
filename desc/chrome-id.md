Menambahkan chat berjalan (danmaku) seperti niconico atau bilibili ke siaran langsung YouTube.

*Pengembangan masih berlangsung, sehingga kinerjanya bisa tidak stabil. Jika tidak berjalan semestinya, muat ulang halaman atau beralih ke miniplayer.*

Untuk cara memasang versi lama, silakan lihat panduan instalasi: <https://github.com/ys-j/YoutubeLiveChatFlusher/wiki/Installation>


FITUR
----------
- Standalone🌐: Tetap bisa menikmati danmaku meskipun panel chat ditutup (pada mode independen).
- Ramah seluler📱: Juga berfungsi di situs seluler (`m.youtube.com`).
- Menyematkan & memindahkan chat📌*: Klik kanan untuk menjeda chat yang menarik secara terpisah, lalu pindahkan ke posisi yang Anda inginkan.
- Terjemahan real-time🔠: Menerjemahkan chat sambil dialirkan, menggunakan terjemahan bawaan browser atau layanan eksternal (Google Translate, LLM lokal, dan lainnya).
- Geser waktu (time-shift)⏳: Atur kapan chat mengalir pada video arsip, lebih cepat atau lebih lambat (pada mode independen).
- Picture-in-picture (fitur beta)📺*: Menampilkan video dan chat yang mengalir bersama-sama di jendela PiP.

*: hanya tersedia di versi desktop


OPSI PENGATURAN (Sorotan)
----------------------
- Kecepatan animasi (kecepatan aliran chat)
- Ukuran font, jumlah baris, tinggi baris
- Font & ketebalan (sintaks CSS, contoh: Roboto, "Noto Sans JP" / 500)
- Item tampilan & warna font per jenis pengguna: pengguna biasa/member/moderator/pemilik channel/akun terverifikasi, Super Chat, Super Sticker/hadiah, member baru/milestone
- Warna & ketebalan garis tepi
- Kepadatan & arah aliran chat
- Daftar kata terlarang
- Detik geser waktu (time-shift)
- CSS definisi pengguna
- Pintasan keyboard

Sama seperti pengaturan kualitas video atau subtitle, panel pengaturan dapat dibuka dari ikon roda gigi.

Penjelasan lengkap ada di GitHub wiki: <https://github.com/ys-j/YoutubeLiveChatFlusher/wiki>
