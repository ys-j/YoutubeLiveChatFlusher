เพิ่มแชทไหลแบบดังมาคุ (danmaku) สไตล์ niconico หรือ bilibili เข้ากับการถ่ายทอดสดบน YouTube

*ตอนนี้ยังอยู่ระหว่างการพัฒนา การทำงานอาจไม่เสถียร หากทำงานผิดปกติ กรุณาโหลดหน้าใหม่หรือสลับไปมินิเพลเยอร์*

หากต้องการใช้เวอร์ชันเก่า กรุณาอ่านคู่มือการติดตั้ง: <https://github.com/ys-j/YoutubeLiveChatFlusher/wiki/Installation>


ฟีเจอร์
----------
- ไม่พึ่งพาแชทข้าง🌐: ดูดังมาคุได้แม้ปิดกรอบแชท (ในโหมดไม่พึ่งพาแชทข้าง)
- รองรับมือถือ📱: ใช้งานบนเว็บมือถือ (`m.youtube.com`) ได้
- ปักหมุดและย้ายข้อความ📌*: คลิกขวาเพื่อพักข้อความที่สะดุดตาเป็นรายอัน แล้วย้ายไปตำแหน่งที่ชอบได้
- แปลแบบเรียลไทม์🔠: แปลข้อความไปพร้อมกับที่มันไหลไปได้ โดยใช้ตัวแปลในตัวเบราว์เซอร์หรือบริการภายนอก (Google Translate, LLM ในเครื่อง ฯลฯ)
- เลื่อนเวลา (Time-shift)⏳: ปรับจังหวะการไหลของข้อความในวิดีโอที่รับชมย้อนหลังให้เร็วขึ้นหรือช้าลงได้อย่างละเอียด (ในโหมดไม่พึ่งพาแชทข้าง)
- Picture-in-Picture (ฟังก์ชันเบต้า)📺*: แสดงวิดีโอและข้อความที่ไหลอยู่ในหน้าต่าง PiP เดียวกัน

*: รองรับเฉพาะเวอร์ชันเดสก์ท็อป


ตัวเลือกที่ตั้งค่าได้ (สรุป)
----------------------
- ความเร็วอนิเมชัน (เร็วช้าตอนไหล)
- ขนาดตัวอักษร / จำนวนบรรทัด / ระยะห่างบรรทัด
- ฟอนต์ / ความหนา (ไวยากรณ์ CSS เช่น Roboto, "Noto Sans JP" / 500)
- รายการแสดงและสีข้อความตามประเภทผู้ใช้: ผู้ใช้ทั่วไป/สมาชิก/Moderator/เจ้าของช่อง/ผู้ใช้ที่ได้รับการยืนยัน, Super Chat, Super Sticker/ของขวัญ, สมาชิกใหม่/หลักไมล์
- สีและความหนาของขอบ
- ความหนาแน่นและทิศทางการไหลของข้อความ
- รายการคำต้องห้าม
- จำนวนวินาทีของเลื่อนเวลา (Time-shift)
- CSS ที่ผู้ใช้กำหนดเอง
- คีย์ลัด (Keyboard Shortcut)

เปิดแผงตั้งค่าได้จากไอคอนรูปเฟือง เหมือนกับการตั้งค่าคุณภาพภาพหรือคำบรรยาย

คำอธิบายรายละเอียดอยู่ใน GitHub wiki: <https://github.com/ys-j/YoutubeLiveChatFlusher/wiki>
